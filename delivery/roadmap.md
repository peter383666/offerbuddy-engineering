# Delivery Roadmap

## Purpose

This roadmap communicates the current delivery sequence for OfferBuddy. Sprint scope is confirmed during Sprint Planning and may change as product and technical learning develops.

## Sprint 0 — Engineering Foundation

**Status:** ✅ Completed

Delivered:

- Project and repository structure
- React and Spring Boot foundations
- Docker Compose with PostgreSQL and Redis
- PostgreSQL integration and Flyway migrations
- GitHub Actions continuous integration
- Initial product, architecture, quality, and delivery documentation

Related documents:

- [Sprint 0 Planning](sprint-0.md)
- [Sprint 0 Review](sprint-0-review.md)
- [Sprint 0 Retrospective](sprint-0-retrospective.md)

## Sprint 1 — First Business Capability

**Status:** 🟡 Planned

Candidate outcomes:

- Google authentication
- Initial application management
- Initial dashboard
- First end-to-end MVP workflow

The committed scope will be recorded in `sprint-1.md` after backlog refinement and Sprint Planning.

## Future Delivery

Future work includes AI-assisted job extraction, resilience testing, search and filtering, application lifecycle improvements, and deployment hardening.

See [Product Backlog](product-backlog.md) for identified work that has not yet been committed to a sprint.
