# OfferBuddy Design System

## Purpose

This document defines the shared layout and visual foundation for all OfferBuddy pages.

The goal is to provide a consistent user experience while keeping the interface simple and focused.

---

# Design Principles

## Less Is More

Only display information that helps users complete their current task.

Avoid unnecessary charts, statistics, decorations, and visual noise.

---

## One Primary Action

Each page should have one clear primary action.

Examples:

Home

- Paste Job Link

Applications

- New Application

---

## Consistency

All pages should share the same layout, spacing, typography, and navigation structure.

Users should immediately understand how each page works.

---

## Daily Workflow

OfferBuddy is designed for frequent daily use.

The interface should reduce clicks and minimise cognitive load.
