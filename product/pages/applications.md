# Applications

## Purpose

The Applications page is the primary workspace of OfferBuddy.

It allows users to manage every job application throughout the entire application lifecycle.

This page replaces the traditional Excel spreadsheet.

---

# Target User

Job seekers managing multiple job applications.

---

# Primary Goals

- Create applications quickly.
- Search applications.
- Filter applications.
- Update application status.
- Review previous applications.

---

# Primary Actions

- Create Application
- Edit Application
- Delete Application
- Search
- Filter
- Sort

---

# Search

Supported fields:

- Company Name
- Position Title

---

# Filters

Status

- All
- Applied
- Interview
- Offer
- Rejected
- Withdrawn

---

# Sorting

Default

Applied Date (Newest First)

Available

- Applied Date
- Updated Date

---

# Table Columns

- Company
- Position
- Location
- Work Arrangement
- Visa Sponsorship
- Status
- Applied Date
- Actions

---

# Display Rules

The application list is sorted by Applied Date descending by default.

Only frequently used information should be displayed.

Detailed information should be accessed from the Application Detail page.

---

# Out of Scope

The following features are excluded from Sprint 1.

- Analytics
- AI Suggestions
- Timeline
- Bulk Actions
- Advanced Filters
- Date Range Filtering

---

# Design Principles

- Application First
- Fast data entry
- Efficient search
- Minimal clicks
- Optimized for daily use
