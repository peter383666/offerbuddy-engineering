# Home

## Purpose

The Home page provides a daily overview of the user's job search progress and offers quick access to the most common actions.

It is designed to answer one question:

> What should I focus on today?

The Home page is an entry point, not a workspace.

---

# Target User

Job seekers who actively apply for jobs every day.

---

# Primary Goals

- Quickly understand today's job search status.
- Continue the current job search workflow.
- Access the most common actions with one click.

---

# Primary Actions

- Create New Application
- Paste Job Link for AI Parsing
- View All Applications

---

# Displayed Information

## Quick Actions

- New Application
- Paste Job Link

---


## Recent Activity

Displays the most recent application activities.

Examples:

- New application created
- Application updated
- Status changed

Only the latest 5 records are displayed.

---

# Navigation

View All Applications

Navigates to the Applications page.

---

# Out of Scope

The following features are intentionally excluded from the Home page.

- Analytics
- Charts
- Reports
- Advanced Filters
- Company Management

---

# Design Principles

- Keep the interface simple.
- Minimize visual distractions.
- One-click access to the most common actions.
- Focus on today's workflow instead of historical data.
